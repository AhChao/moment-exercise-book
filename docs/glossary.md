# 詞彙對照表

畫面上的字一律照此表。表上沒有的詞，先加進表再用；一詞一義。

## 產品詞

| 畫面用詞 | 指什麼 | 不用 |
|---|---|---|
| 練習本 | 整個 App 與其中的題目集合 | 課程、教材、任務 |
| 章 | 一組主題相近的題目 | 單元、模組 |
| 題 | 單一練習 | 關卡、任務、作業 |
| 畫格 | 一題裡等待放照片的位置，最多四格 | 插槽、格子、slot |
| 相簿 | 已拍與已匯入的全部照片 | 圖庫、資料庫 |
| 觀察 | 拍完後對照片差異的記錄欄 | 筆記（單獨）、備註 |
| 反思 | 針對自己拍攝選擇的記錄欄 | 心得、回饋 |
| 完成 | 一題被標成完成 | 通過、達成 |
| 備份檔 | 匯出的 ZIP | 存檔、快照、archive |

## 介面詞（實作時新增）

| 畫面用詞 | 用在哪 |
|---|---|
| 主選單 | 底部分頁列的無障礙名稱 |
| 難度 n / 3 | 題目難度圓點的無障礙名稱 |
| 夜間 | 題目列上的需求標籤 |
| 保護資料 / 已受保護 / 尚未受保護 | 儲存空間的保護狀態 |
| 鏡頭、章 | 相簿的篩選標籤 |

## 攝影詞

快門（不寫快門速度）、ISO、曝光補償（單位 EV）、白平衡、色溫（單位 K）、倍率（0.5×、1×、5×）、對焦距離、陰影、亮部、曝光（僅用於後製滑桿，意為整體亮度）、暖度（後製滑桿）、雜訊、動態模糊、景深、構圖。

## 動作詞

| 用 | 不用 |
|---|---|
| 拍攝 | 擷取、捕捉 |
| 重拍 | 重新拍攝、Retake |
| 從相簿選取 | 上傳、匯入照片（匯入僅用於備份檔） |
| 匯出備份 / 匯入備份 | 下載、上傳、還原 |
| 刪除 | 移除（照片）、清除 |
| 調整 | 編輯、修圖、處理 |

## 資料詞（畫面上如何稱呼拍攝資料）

拍攝資料（不寫 EXIF、metadata、中繼資料）；欄位名：快門、ISO、焦段、鏡頭（主鏡頭、超廣角、長焦、前鏡頭）、拍攝時間。

## 狀態詞

| 情境 | 用詞 |
|---|---|
| 相機未授權 | 未取得相機使用權限 |
| 手機不支援某項控制 | 這支手機的相機沒有提供此項控制 |
| 需要以相機 App 拍攝 | 此畫格改由手機相機 App 拍攝後，從相簿選取 |
| 尚未有內容 | 空狀態句用名詞短語，例如「相簿目前沒有照片」 |

## 標點與用字

名詞「紀錄」、動詞「記錄」；中文句內標點全形；數值與單位保持半形（ISO 100、1/125、5×）。

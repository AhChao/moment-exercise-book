# Steven 提供的 15 題範例（原文）

曝光三要素
1. 快門
靜物 / ISO 100 / 1/30、1/125、1/500 / 觀察：亮度、手震、動態模糊
2. ISO
室內靜物 / 快門固定 1/125 / ISO 100、400、1600 / 觀察：亮度、雜訊、細節
3. 快門 x ISO
同一靜物、亮度盡量一致 / 1/30 + ISO 100、1/125 + ISO 400、1/500 + ISO 1600 / 觀察：同樣亮，照片有什麼不同

曝光與陰影
4. 曝光
戶外高反差風景 / 曝光 -1 / 0 / +1 / 觀察：天空、高光、暗部
5. 陰影
使用第 4 張 / Shadows -50 / 0 / +50 / 觀察：暗部細節
6. 暗部極限
室內 -> 窗外陽光 / 正常 / Shadows +50 / 觀察：暗部細節、雜訊、畫面是否變平

白平衡
7. 白平衡
室內黃燈 / 3000K / 4500K / 6000K / 觀察：白色物體、整體色調
8. 白平衡氛圍
黃昏或夜景 / 一張偏暖、一張偏冷 / 觀察：哪張比較「真實」、哪張比較「有感覺」

焦段 / 視角
9. 不同焦段 + 移動位置
拍同一個人 / 0.5x / 1x / 5x / 每次移動自己，讓人物大小差不多 / 觀察：臉型、背景壓縮、透視
10. 不同倍率，不移動
人與手機位置固定 / 0.5x / 1x / 5x / 觀察：視野變窄、放大

夜景
11. 夜景快門 x ISO
固定景物 / 1/250 + 高 ISO、1/15 + 低 ISO / 亮度盡量接近 / 觀察：雜訊 vs 手震
12. 夜景動態
晚上拍走動的人 / 快門 1/30 vs 1/250 / ISO 自行補亮度 / 觀察：亮度 vs 凍結動態

綜合
13. 風景曝光取捨
天空 + 樹 + 建築 / 曝光 -1 / 0 / +1 / 選擇你想保留的東西
14. 風景陰影取捨
Shadows -50 / 0 / +50 / 觀察：立體感、暗部細節、雜訊
15. 自由創作
自選風景 / 自選 0.5x / 1x / 5x / 自選快門 / ISO / 自選曝光 / 陰影 / 白平衡 / 記錄：我為什麼這樣設定？
